# Data Processing Addendum — operator template

Complete this template with counsel before executing it. The customer is normally the controller and
the ProcureX operator the processor for customer-submitted procurement data. Define instructions,
confidentiality, security measures, subprocessors, cross-border transfers, incident notification,
assistance with data-subject requests, deletion/return, and audit rights.

Current candidate subprocessors must be disclosed based on the deployed configuration: Render for
hosting, the selected OIDC provider for identity, Cloudinary for private document objects, and Google
Gemini only for the specifically configured analysis data path. Do not list a provider that is not
actually used, and do not send source documents to a model unless the customer has authorized it.
